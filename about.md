# AI Level Builder

Adds a pink **AI** button to the level editor, next to undo / redo / delete.

- **Generate** builds a level on your device: pick a style, difficulty and length, or just type something like `long hell wave level, extreme`. No account needed.
- **Ask AI** sends your request to Claude, which can build levels, add parts, recolour, and move, change or delete existing objects. It needs your own Claude API key (set it in this mod's settings).

Generated parts are added as one step, so a single undo removes them. Always playtest what you get.
